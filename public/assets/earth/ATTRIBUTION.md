Day map was obtained from the Commons copy of the creator's work because the
creator's day-map endpoint returned HTTP 403. The creator and license are confirmed
on both the collection page and the Commons file page.

Files are unmodified. In BEYOND, the day map is lit on a sphere, the grayscale cloud
map is used as an alpha mask, and the globe is posed for the fictional journey.
Lighting, size, atmosphere thickness, travel path and launch location are artistic
presentation, not a physical model or a live satellite view. The collection uses
NASA imagery/elevation data with adjusted colors and seasonal coverage.

The launch cloud/mist particle mask and atmosphere shader are original project code.
