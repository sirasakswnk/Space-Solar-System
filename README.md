# BEYOND

เว็บไซต์สำรวจระบบสุริยะสำหรับคอมพิวเตอร์ ใช้ React, TypeScript, Vite และ React Three Fiber
ข้อกำหนดอยู่ใน `plan.md` และสถานะการพัฒนาอยู่ใน `work/progress.md`

## เปิดรันบน Windows

ใช้ Node.js ตาม engines ของ dependencies (เครื่องที่เริ่มงานใช้ v24.20.0)

```powershell
npm.cmd ci
npm.cmd run dev
```

เปิด URL ที่ Vite แสดงใน terminal; ค่าเริ่มต้นคือ `http://127.0.0.1:5173`

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run preview
```
