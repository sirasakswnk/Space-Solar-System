## เปิดรันบน Windows

ใช้ Node.js ตาม engines ของ dependencies (เครื่องที่เริ่มงานใช้ v24.20.0)

```powershell
npm.cmd ci
npm.cmd run dev
```

เปิด URL ที่ Vite แสดงใน terminal; ค่าเริ่มต้นคือ `http://127.0.0.1:5173`

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

S10a ถ้าระบบตั้ง "ลดการเคลื่อนไหว" (prefers-reduced-motion): ไม่มีการเบนตามเมาส์; กระโดดไกล (เมนูจุดหมาย, Home/End) และเข้า/ออกสำรวจ/เลือกจุดข้อมูลเป็นการตัดภาพพร้อมจางเข้า 0.4 วินาที แทนการบินกล้อง; การเลื่อนปกติยังนุ่มเหมือนเดิม
S10b ปุ่ม “ตั้งค่า” ข้างเมนูจุดหมาย: สวิตช์ลดการเคลื่อนไหว (ค่าเริ่มต้นตามระบบ เลือกแล้วคงค่าแม้ระบบเปลี่ยน) และคุณภาพภาพ มาตรฐาน/เบา (เบา = ความละเอียด 0.75 เท่า ราว 56% ของพิกเซล); เริ่มใหม่ไม่ล้างค่า; ปิดหน้าแล้วค่าไม่ถูกจำ
S10c ใต้แถบความคืบหน้าแสดง “กำลังโหลดภาพดาว x/9 ไฟล์” จากไฟล์ที่โหลดเสร็จจริง (ไม่มี % แต่งขึ้น) และซ่อนเมื่อครบ; ถ้าไฟล์ใดล้มเหลวจะบอกชื่อดาวพร้อมปุ่ม “ลองโหลดใหม่” ซึ่งโหลดใหม่เฉพาะไฟล์ที่ล้มเหลว ระหว่างนั้นใช้สีสำรองและเดินทาง/สำรวจได้ตามปกติ
S10d-1 ถ้าเบราว์เซอร์สร้าง WebGL ไม่ได้ (ตรวจก่อนเริ่ม หรือฉากล้มเหลวภายหลัง) จะแสดงหน้าเนื้อหาแทนจอว่าง: เส้นทาง, ข้อมูลและจุดข้อมูลของดาวทั้งเจ็ด, แหล่งอ้างอิง และแผนที่ภาพดาวเป็นภาพนิ่ง
S10d-2 ตรวจคีย์บอร์ดทั้งหน้า: ทุกจุด focus มีกรอบมองเห็นและไม่ถูกบัง ใช้คีย์บอร์ดล้วนได้ครบ (เมนู/ตั้งค่า/สำรวจ/จุดข้อมูล/หมุน/Escape/End/ภาพรวม/เริ่มใหม่); แผงภาพรวมเลื่อนลงใต้แถบความคืบหน้าเมื่อมีข้อความโหลด จึงไม่บังปุ่มลองใหม่

ในโหมดสำรวจ ลากบนฉากเพื่อหมุน ใช้ล้อเมาส์ซูม หรือใช้ปุ่มแทนได้
